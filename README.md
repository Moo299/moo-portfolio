# README: เว็บไซต์ Portfolio นักศึกษาปริญญาตรี (เทคโนโลยีธุรกิจดิจิทัล)

เว็บไซต์แฟ้มสะสมผลงาน (Portfolio) สไตล์ Modern Glassmorphism ทันสมัย สวยงาม พรีเมียม ออกแบบมาโดยเฉพาะสำหรับนักศึกษาปริญญาตรี **สาขาวิชา/แผนกเทคโนโลยีธุรกิจดิจิทัล (Digital Business Technology)**

---

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5**: โครงสร้างหน้าเว็บแบบ Semantic และรองรับการทำ SEO
- **Bootstrap 5.3 & Icons**: Layout Grid ระบบ Responsive และไอคอนคุณภาพสูง
- **Custom CSS (Vanilla)**: รองรับโหมด Dark / Light Theme, Glassmorphism, Micro-animations, Floating Cards และ Gradient Accents
- **Vanilla JavaScript**: ควบคุม Typing animation, ตัวกรองผลงาน (Category Filter), Modal ป๊อปอัป, Form validation และ Animated Progress Bars

---

## 🚀 ฟังก์ชันและส่วนประกอบของเว็บไซต์
1. **Hero Section**: ข้อความพิมพ์อัตโนมัติ (Typing Effect), สถานะพร้อมเริ่มงาน (Open for Opportunities), ภาพโปรไฟล์พร้อมป้ายลอย (Floating Badges)
2. **About Me**: ประวัติการศึกษา, เกรดเฉลี่ย, เป้าหมายวิชาชีพ (Career Objective) และสถิติสำคัญ
3. **Skills & Capabilities**: จัดกลุ่ม 3 มิติหลัก:
   - *Business & Marketing*: E-Commerce, Meta/TikTok Ads, SEO, Business Model Canvas
   - *Data & Analytics*: Power BI, Excel Advanced, GA4, SQL, Data Cleansing
   - *Technology & Design*: HTML/CSS/JS, Figma UI/UX, WordPress, Canva
4. **Portfolio & Projects Showcase**:
   - กรองผลงานแยกหมวดหมู่ (E-Commerce, Data Analytics, Digital Marketing, Web & UI/UX)
   - คลิกดูรายละเอียดแบบเต็มใน Modal
5. **Education & Certifications**:
   - Timeline ประวัติการศึกษาและการฝึกงาน
   - บัตรแสดงเกียรติบัตร (Google Digital Garage, Microsoft Power BI, Meta Certified, Hackathon Winner)
6. **Contact Form & Socials**: แบบฟอร์มติดต่อพร้อม Interactive Toast Notification และปุ่มดาวน์โหลด Resume

---

## 📂 โครงสร้างโฟลเดอร์ (Project Structure)
```
├── index.html        # หน้าเว็บหลัก
├── css/
│   └── style.css     # ไฟล์สไตล์ชีตหลัก (Custom Variables, Dark/Light mode, Glassmorphism)
├── js/
│   └── main.js       # ฟังก์ชันการทำงานทั้งหมด (Interactive Logic)
└── README.md         # เอกสารแนะนำการใช้งาน
```

## 🌐 วิธีเปิดใช้งาน
- สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Firefox, Safari) ได้โดยตรงทันที
- หรือเปิดผ่าน Live Server บน VS Code
